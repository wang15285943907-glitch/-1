# 逐句精读 · 英语阅读讲义排版器

一个不需要构建工具的静态网页项目：把阅读题照片发给当前 ChatGPT 对话，网页可按年份、科目和篇目自动打开官方站点 PDF 搜索；ChatGPT 根据照片线索自行查找并核对官方 PDF，再把生成的讲义 JSON 导入网页，排成适合屏幕阅读和打印的逐句对照讲义。用户不需要先找到或上传 PDF。

## 使用方式

1. 用浏览器打开 `index.html`。本地运行时可在项目目录启动 `python -m http.server 8080`，然后访问 `http://localhost:8080`。
2. 在当前 ChatGPT 对话上传阅读题照片。年份、科目或篇目知道多少填多少；点“自动查找官方 PDF”，网页会用这些线索打开限定在高校域名的 PDF 搜索结果。也可点“复制照片精读请求”，让当前 ChatGPT 对话自行联网查找和讲解。
3. ChatGPT 从照片识别检索线索，打开官方 PDF，核对发布机构/托管高校、年份、科目、文章编号、文章和题目。不能核验时报告搜索范围和结果；不会要求用户补交 PDF，也不会用 OCR 或培训机构转载代替原文。
4. 本地 PDF 文字提取是可选项。若已有官方 PDF，可展开“可选：在本地提取官方 PDF 文字层”；页面只读取 PDF 自带的文字层，扫描图片 PDF 没有文字层时会停止，不运行 OCR。
5. 把 ChatGPT 返回的 JSON 导入或粘贴到“讲义数据”编辑器，点击“应用并排版”。
6. 点击“打印 / 保存 PDF”，在浏览器打印窗口选择“另存为 PDF”。

页面会将英文原句与中文翻译逐句相邻排版；重点词标红；每段词汇与短语放在右侧；题目答案项和对应原文证据分别着色，并提供从题目跳回证据的链接。讲义可显示 PDF 标题、发布机构、官方链接和来源核验说明。窄屏下，词汇侧注会移到段落下方。

## 实现说明

- 页面不调用 AI API，也不做图片 OCR。网页的“自动查找官方 PDF”按钮会构造包含年份、考试科目、篇目、`site:edu.cn` 和 `filetype:pdf` 的搜索请求并打开 Bing 结果页，同时提供百度备用搜索链接；搜索结果是线索，不等于已核验。当前 ChatGPT 对话负责查看照片、进一步联网检索、核验官方 PDF 和生成逐句翻译及题目解析。
- 用户不需要先找到、下载或上传 PDF。可选 PDF 由浏览器本地解析；PDF.js 从公共 CDN 按需加载。扫描版 PDF 没有可复制文字层时，页面停止提取，不会用 OCR 补字。讲义 JSON 保存于当前浏览器的本地存储，不发送给项目服务器。
- 以照片作为题目定位线索；讲解前必须报告官方 PDF 标题、发布机构或托管高校、PDF URL 和匹配依据。无法核验时报告搜索范围和结果，不要求用户提供 PDF，不以搜索摘要、培训机构转载或模型记忆代替原文。
- 示例文章是为展示排版制作的虚构内容，不是考研真题。
